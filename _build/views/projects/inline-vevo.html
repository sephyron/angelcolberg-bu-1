Vevo

Onboarding for retention

In order to unify the experience across all our devices we decided to do an expansive redesign with the explicit goal of increasing retention and relevance.

The first time user experience for onboarding new users unto our recommendation engine and to prove out a hypothesis that would increase our engagement and retention by having users create playlists. This was based on quantitative behavioural observations and qualitative follow up interviews with some of those same users.

Use Case

Onboarding for retention

Turn first session into a habit

The onboarding overview introduces recommendations and playlist creation as an early engagement path for new viewers.

Result

The experience gave users a reason to personalize Vevo before the first session ended.

Recommendation entry point

Explain why personalization matters

This screen frames the value of recommendations and gives users an approachable first decision rather than dropping them into an empty home.

Result

Users understood the purpose of onboarding before being asked to provide preferences.

Preference selection

Make preference capture lightweight

The selection flow collects signals that can improve recommendations while keeping the interaction focused and easy to skip or revisit.

Result

Personalization became a short, understandable exchange rather than a form.

Playlist creation

Convert preference into action

This screen connects the user’s selected interests to playlist creation, giving the recommendation engine a concrete behavioral signal.

Result

Users moved from choosing interests to building something they could return to.

Personalized home

Make relevance visible

The personalized home demonstrates how onboarding choices change the content hierarchy and make the service feel tuned to the viewer.

Result

Personalization was visible immediately, reinforcing the value of completing onboarding.

Cross-device playback

Carry the relationship across devices

This screen extends the onboarding and recommendation model into playback contexts beyond the first device.

Result

Users could recognize their personalized experience wherever they watched.

Retention feedback loop

Use behavior to improve the next session

The final state shows how viewing and playlist behavior can feed future recommendations and create a loop between discovery and return visits.

Result

The redesign connected first-use decisions to longer-term relevance and retention.
