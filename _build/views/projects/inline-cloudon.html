CloudOn

Mobile Collaboration and Productivity

I led a mobile-first redesign of CloudOn across phone, tablet, and web. I used usability tests, interviews, and contextual inquiries to understand how people moved between files and devices. The clearest problem was navigation: users had to retrace their steps whenever they changed context. I redesigned it as a drill-down model and prototyped the pattern across breakpoints so the same mental model held everywhere.

Use Case

Cross-device productivity

One workspace across devices

The primary workspace established the shared information model for documents, folders, and collaboration across desktop and mobile. The redesign made the same work state legible at every breakpoint.

Result

Users could move between devices without relearning where files, actions, and shared content lived.

Mobile notifications

Actionable feedback on mobile

This study defined notification density, hierarchy, expansion, and dismissal states for a small screen. It connected system feedback to the document tasks users were already performing.

Result

Notifications became compact, readable, and actionable without obscuring the active workspace.

Tablet navigation

Drill-down navigation model

The tablet flow tested how users could move from global folders into nested content while retaining orientation. The diagram maps the transitions between navigation, folder space, preview, and edit states.

Result

A focused drill-down model reduced navigation ambiguity and made deeper file structures easier to scan.

Editing and preview states

Keep document actions in context

This flow explored the handoff between preview and editing, including the moments where users choose an application or return to the file structure.

Result

Preview, edit, and return actions became explicit states instead of disconnected destinations.

Web file management

Scale the model to desktop

The web view applies the same file, sharing, and document controls to a larger information surface, giving users more room for folders, metadata, and persistent navigation.

Result

The responsive model preserved the cross-device mental model while taking advantage of desktop space.
